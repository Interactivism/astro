**Subject:** The UX problem with attribution dashboards

---

Hi Peter,

A specific pattern we kept bumping into at tvScientific: the advertisers who churned early usually hadn't gotten lost in the product — they'd gotten confused by the reporting. Not because the data was wrong, but because the attribution interface required them to understand our model before they could trust what they were seeing.

The fix wasn't more documentation. It was redesigning how data was presented so the logic was visible in the interface itself.

I suspect measurement platforms like Podscribe have the same challenge, maybe even more acutely — podcast attribution is newer, so buyers need extra reassurance that the method is sound. That's a design problem as much as a data problem.
